# Contributing

Use Node 22+ and Python 3.13+. Install `requirements-dev.txt` and a Playwright
Chromium browser as described in the README. Run `./scripts/build.sh` (or
`scripts/build.ps1` on Windows) and `npm test`. Check formatting with
`git diff --check` and preserve the existing style and SPDX headers.

Keep pull requests small and focused. No DCO sign-off is required.
Contributions are licensed under Apache-2.0.
